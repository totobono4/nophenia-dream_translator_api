# Translation Mod API for nophenia
This mod is for development purposes to make translation mods easier.
You can use [godot-override-mod-loader](https://github.com/totobono4/godot-override-mod-loader/tree/main) or [godot-mod-loader](https://github.com/GodotModding/godot-mod-loader/tree/4.x-dev) to install.
